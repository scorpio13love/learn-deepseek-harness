# DSH 面试自测（本地版）

直接双击打开 [`index.html`](index.html) 即可。

- 96 道单选，覆盖 28 课 + 12 道综合题
- 7 个知识域：内核、上下文、组合、执行边界、产品面、质量、综合
- 每题提交后立即判分并显示解释
- 最后交卷：总分、知识域分布、错题回顾
- 全部在浏览器本地计算，不联网，不保存答案到服务器

也可以只练一个知识域，或交卷后“只做错题”。

文件：

```text
docs/quiz/
  index.html      # 交互页面
  quiz-data.js    # 题库
```

> 最高分用 `localStorage` 存在本机浏览器里；清除站点数据会重置。
