# DSH 面试自测（6 个 Part）

直接双击打开 [`index.html`](index.html) 即可。

- 6 个 Part，约 30 题/Part：概念题 166 道 + coding 28 道
- 概念题覆盖 28 课与综合题，题型包括单选、多选、判断
- 每个 Part 最后几题是该 Part 的 AI Coding 任务
- 6 个 Part：内核、上下文、组合、执行边界、产品面、质量；另有综合
- 每题提交后立即判分并显示解释
- 最后交卷：总分、知识域分布、错题回顾
- 全部在浏览器本地计算，不联网，不保存答案到服务器

也可以只练一个知识域，或交卷后“只做错题”。

文件：

```text
docs/quiz/
  index.html      # 交互页面
  quiz-data.js    # 题库
```

> 最高分用 `localStorage` 存在本机浏览器里；清除站点数据会重置。
